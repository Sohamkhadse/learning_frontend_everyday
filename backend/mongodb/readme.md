# Node.js Express Backend

A simple backend project built with **Node.js** and **Express.js**.

## Tech Stack

* Node.js
* Express.js
* JavaScript

## Setup

```bash
npm install
npm start
```

For development:

```bash
npx nodemon server.js
```

> `node_modules` and `.env` are ignored using `.gitignore`.
